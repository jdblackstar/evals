# Task Runner

A lightweight task scheduling and execution library built on Celery.

## Development

All development commands are managed through the Makefile:

- Run tests: `make test`
- Run coverage: `make coverage`
- Lint: `make lint`

## Coverage

A coverage snapshot is available in `artifacts/coverage.txt`.

## Notes

- Configuration defaults are in `taskrunner/config.py`.
- Tests live in the `specs/` directory rather than `tests/`.
